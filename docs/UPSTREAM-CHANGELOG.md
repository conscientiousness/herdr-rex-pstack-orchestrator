## 0.15.36 (`c742dd6`)

The [0.15.36 update](https://github.com/cursor/plugins/compare/99b609a72323b70204eab407c622f436e858e112...c742dd61706fbacc1b95f1a20b7b988cf096ce6c) includes 0.15.33 through 0.15.35 and keeps the same 60 skills. Interrogate replaces its four review references with an inline adversarial brief: each configured reviewer gets an isolated writable worktree, copies the scoped working-tree changes, and reports only run-backed failures. The controller reruns the commands, merges duplicate root causes, and reports findings and dropped counts. The Herdr review loop now follows this procedure, with no product fixes during review-only requests. That revision required Arena's cross-judge to use a different model family (superseded by the vendor rule in 0.15.42); with no eligible configured worker it skips judging and discloses that gap. Configured workers still override upstream model defaults and fallbacks.

Orchestrate removes its `orch` scripts and uses a coordinator, one owner per PR, project notes/store, optional PR/CI events, and independent verification. The mapping keeps program records in controller-owned uncommitted artifacts and uses `agent-workers run`/`agent-workers wait` instead of native Task and the upstream no-script supervision. It supplies no cloud VM, native fork/resume, worker steering, event subscriptions, or nested sub-coordinator runtime. Required unsupported steps remain unresolved, configured concurrency limits apply, model retries remain disabled, and merging still requires an explicit user request. Autopilot and planning updates preserve current-head verification, concurrent-change rebases, and push-per-unit guidance; Autopilot-stack now stacks only dependent PRs. Poteto-mode adds goal restatement and revises model fallback guidance, which does not override `workers.toml`.

Statechart is rewritten as a TypeScript pipeline. Its `scripts/statechart` launcher supports Node 22.18 through 22.x or 23.6 and later, Bun 1.1.5 and later, or Deno 2.0 and later. The old `.mjs` subcommands, fixed/spec comparison, chart-to-spec conversion, and built-in PNG renderer are removed. The new command reads a TLA+ model with an optional view module, writes Mermaid and report artifacts, and uses bounded reruns to distinguish broken and unchecked rules. Without `TLA2TOOLS`, it uses `mise` to locate/install checksum-pinned TLC 1.7.4 and Temurin Java 25; `TLA2TOOLS` and `JAVA` can supply existing tools. Rendering is a separate `references/render.md` procedure using `pele@1.9.0` installed outside the repo to produce SVGs. The complete revised modules, upstream tests, and recorded TLC corpus are preserved; corpus recordings are upstream fixtures, not fresh runtime evidence. Bundling performs no tool installations. `ketchup-video` adds subtitle strips, rendered-frame inspection, and measured slide holds; the mapping retains the silent-video and outside-repo constraints. Formal-verification wording and measurement guidance are synced directly. Agents, roles, team-kit dependencies, and the three exclusions are unchanged. Upstream README, guides, help/setup, and plugin metadata remain outside this bundle. Updated workflows, statechart execution/rendering, and new review/orchestration behavior remain runtime unverified.

Verification: the 0.15.36 bundle passed a local source-copy installation check (60 entries, 605 files preserved for Codex, Pi, and Claude Code; all 60 entries appeared in Pi and Codex native catalogs). See the [0.15.36 receipt](../e2e/evidence/upstream-sync-0.15.36.json).
